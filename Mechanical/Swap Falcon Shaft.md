# Swap Falcon Shaft

## Tools and Parts Needed

### Tools

- T10 bit
- T8 bit

### Parts

- New rubber O-ring (for slip ring replacement)
- New bearing
- M2 bolts
- M3 bolts
- Loctite

## Procedure

1. Remove the Falcon casing using a T10 bit.
2. Unscrew the shaft bolts using a T8 bit.
3. Remove the slip ring and bearing.
4. Replace the slip ring with the new rubber O-ring.
5. Replace the bearing with the new bearing.
6. Reinstall the shaft bolts using M2 bolts with Loctite.
7. Reinstall the casing bolts using M3 bolts with Loctite.
