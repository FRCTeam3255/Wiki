# Post-Competition Checklist

Complete this checklist at the venue after the final match and **while the pit is being packed**. Do not wait until the team gets home. Leave the robot disabled while configuring its electronics.

Before packing the robot's electronics, restore its normal at-home practice configuration:

- [ ] **Radio:** Configure it for the robot, not field use. Restore the team number, robot SSID, and password, and label the radio with the network information. Follow [Configuring the Radio](../Software/Configuring%20the%20Radio.md).
- [ ] **roboRIO:** Set the team number to 3255 with the roboRIO team number setting tool. Confirm the installed image is appropriate for the robot code; only re-image if needed, following [Flashing roboRIO](../Software/Flashing%20RIO.md).
- [ ] **Limelight(s):** Restore the robot's team number and network settings. Use the robot's README or [Pre-Competition Prep](Pre%20Comp%20Prep.md) for the correct settings. Do not flash firmware just for this reset; flashing can erase Limelight settings and position data.
- [ ] **Verify:** Confirm the Driver Station can connect to the robot and that each Limelight is reachable with its expected settings. Resolve any issues before packing.
- [ ] Pack the configured electronics with the robot so they are ready for practice at home.

If a setting is unknown or a device cannot be verified, ask a mentor before packing it.
